(`docs/BENCHMARK-PLAN.md`), following

## Results
Average FPS: **15.016779** (4475 frames / 298s, `Game time = 4:58`,
  captured verbatim from `FPS.TXT`). **PASS.** Frame-time samples:
  "4474 used, 0 rejected any category" -- clean.

  **Fourth appearance of this exact 15.016779fps/4475-frame signature**
  across the campaign (486DX2-50+ViRGE, 486DX2-66+ViRGE, and the
  original Am5x86-133+Mach64 datum, all today or 2026-09-03, all on a
  build carrying the same pacer fix). At this point this reads as the
  deterministic frame count/duration the pacer produces for any
  uninterrupted life run flat against the 15fps ceiling, independent of
  CPU tier and video card -- not a coincidence needing further
  explanation. Worth confirming it holds a fifth time on Pentium
  OverDrive 83, the one remaining ViRGE cell.
1% low: RUNMANIFEST `fps_p50=15.00`, `fps_p95=14.96`. Continues the
  `fps_p95` progression with increasing CPU headroom seen across this
  ViRGE sweep: 14.80 (486DX2-50) -> 14.94 (486DX2-66) -> 14.96
  (Am5x86-133) -- consistent with more CPU slack widening the margin on
  the slower-tail frames, not a red flag.
Simulation rate: locked at the 15fps design ceiling, pacer-bound, as
  expected -- this chip has the most headroom of any CPU tier measured
  against ViRGE so far.
Audio underruns: not instrumented. `AUDIO_PRESENT` confirmed multiple
  times mid-run (wide spectral spread, `tone_like=false`). Tier-matched
  build, no pitch/tempo mismatch to caveat.
