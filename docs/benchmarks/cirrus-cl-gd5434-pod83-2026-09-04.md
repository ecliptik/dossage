# Benchmark -- Cirrus CL-GD5434 + Pentium OverDrive 83, first cell of the Cirrus CPU-tier sweep

Opens the Cirrus CPU-tier sweep (the ViRGE sweep closed earlier the same
day at 4/4 CPUs PASS; Cirrus previously had only a 486DX2-66 datum,
pre-merge). Also a full card swap (ViRGE out, Cirrus in) plus a CPU swap
(Am5x86-133 out, Pentium OverDrive 83 in) in one go. Driven on the rig
by `vcctrl-c3`; coordinated/recorded by this session.

## Results
Average FPS: **15.016779** (4475 frames / 298s, `Game time = 4:58`,
  captured verbatim from `FPS.TXT`). **PASS.** Frame-time samples:
  "4474 used, 0 rejected any category" -- clean.

  **Sixth appearance of this exact 15.016779fps/4475-frame signature**
  across the campaign, and the **first on a banked (not LFB) card** --
  every prior appearance (486DX2-50/486DX2-66/Am5x86-133/POD83, all
  ViRGE; the original Am5x86-133+Mach64 datum) ran LFB. At the time this
  was written, this looked like the figure was fully CPU-tier- and
  video-path-independent. **Correction, same day, from the very next
  cell run on this card**: `docs/benchmarks/cirrus-cl-gd5434-486dx2-66-2026-09-05.md`
  found a real, reproducible exception -- Cirrus (banked) + 486DX2-66
  lands one second longer (299s, same 4475 frames) than this figure,
  reproduced identically across two independent lives. So: the
  signature holds at every CPU tier on LFB, and at this CPU tier
  (POD83) on banked, but is not universal across the banked path --
  read this note's "conclusively established" claim as wrong, not
  merely incomplete, per this project's own record-correction
  discipline, and see that file for the actual data and working
  explanation.
1% low: RUNMANIFEST `fps_p50=15.00`, `fps_p95=14.96` -- lands almost
  exactly where the ViRGE+POD83 leg did (`14.97`), consistent with
  `fps_p95` tracking CPU tier, not video card.
