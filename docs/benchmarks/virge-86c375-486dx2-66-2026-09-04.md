# Benchmark -- S3 ViRGE 86C375 + 486DX2-66, re-confirmed on the merged fix build

Re-confirms the port's original reference CPU/card pairing
(`docs/benchmarks/virge-86c375-2026-09-03.md`, 14.817881fps) against the
merged pacer-timing (`0036`) and audio-tier (`0038`-`0041`) fixes. That
earlier run's own Notes flagged this exact gap: the audio-tier fix's fps
effect "was never independently re-measured on this CPU/card
combination" -- 486DX2-66 has considerably more pacer slack than
486DX2-50, so the effect was expected to be small, but "expected small"
was never confirmed. This run confirms it. CPU-only swap from the
486DX2-50+ViRGE leg earlier the same day
(`docs/benchmarks/virge-86c375-486dx2-50-2026-09-04.md`) -- card
untouched, so no UVCONFIG re-run was needed or done. Driven on the rig
by `vcctrl-c3`; coordinated/recorded by this session.

## Results
Average FPS: **15.016779** (4475 frames / 298s, `Game time = 4:58`,
  captured verbatim from `FPS.TXT` on the first life -- stdout redirect
  used from the start this time, no re-run needed). **PASS.** Frame-time
  samples: "4474 used, 0 rejected any category" -- clean.

  **Identical to six decimal places to the 486DX2-50+ViRGE datum from
  earlier the same day, and to the Am5x86-133+Mach64 datum from
  2026-09-03** -- the third independent CPU/card combination to produce
  this exact 15.016779fps/4475-frame signature. This is what a clean
  hit on the design ceiling (`lockedFrameRate=15`) looks like when a
  life happens to land on this particular frame/duration alignment; not
  a coincidence needing further explanation, but a strong repeatability
  signal for the fixed build.
1% low: RUNMANIFEST `fps_p50=15.00`, `fps_p95=14.94`. The `fps_p95`
  figure is slightly higher here than the 486DX2-50 leg's (`14.80`) --
  read as the extra CPU headroom widening the margin to the pacer
  deadline on the slower-tail frames, not a red flag; the 50/66 gap in
  `fps_p95` (14.80 vs. 14.94) while `fps_p50` and the plain average are
  identical is consistent with 486DX2-66 having comfortably more slack
  than 486DX2-50 even though both comfortably clear the KPI line.
Simulation rate: locked at the 15fps design ceiling, pacer-bound, as
  expected for this CPU tier (originally established pre-pacer-work,
  reconfirmed here post-fix).
Audio underruns: not instrumented. `AUDIO_PRESENT` confirmed multiple
  times mid-run (wide spectral spread, `tone_like=false`). Tier-matched
  build, so -- unlike the original 2026-09-03 ViRGE+486DX2-66 leg -- no
  pitch/tempo mismatch to caveat.
Peak memory: not measured.
